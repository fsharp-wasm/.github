# Code of Conduct

We are committed to a respectful, harassment-free environment.

## Expected Behavior

- Be respectful
- Accept feedback
- Collaborate constructively

## Unacceptable Behavior

- Harassment
- Abuse
- Discrimination

## Enforcement

Maintainers are responsible for enforcement.

Based on Contributor Covenant:
https://www.contributor-covenant.org/

## Enforcement

The maintainers remove comments, commits and issues that break these rules and may block contributors who do so repeatedly. To report a problem, write privately
to an organisation owner on GitHub ([@aiqs4](https://github.com/aiqs4)); reports are treated confidentially.
