# Getting help

- **A question or an idea:** [Discussions](https://github.com/fsharp-wasm/fsharp-wasm/discussions).
- **A bug, or a program that does not compile:** an issue in the repository concerned, with the F# source and the command that fails. The compiler's
  [docs/STATUS.md](https://github.com/fsharp-wasm/fsharp-wasm/blob/main/docs/STATUS.md) lists what is known not to work yet.
- **How to start:** [Getting started](https://fsharp-wasm.github.io/docs/getting-started); what runs where: the [demos](https://fsharp-wasm.github.io/demos),
  the [examples](https://fsharp-wasm.github.io/examples) and the [backend](https://fsharp-wasm.github.io/backend).
- **A security problem:** [SECURITY.md](SECURITY.md) — privately, please.

This is an early project run in the open; answers take the time they take.
