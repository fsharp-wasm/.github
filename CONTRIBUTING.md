# Contributing to fsharp-wasm

Welcome — this project aims to build a modern F# → WebAssembly toolchain.

## Vision

- Bring F# to WebAssembly
- Enable high-performance, type-safe apps
- Build foundation for future platforms

## Requirements

- .NET SDK (>= 8)
- Git

## Setup

git clone https://github.com/fsharp-wasm/fsharp-wasm.git
cd fsharp-wasm
dotnet build

## Testing

dotnet test

## Guidelines

- Keep changes small
- Write clear commits
- Add tests where possible

## Communication

Open an issue before large changes.
